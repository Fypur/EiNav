Mode livraison

Touche la grille pour choisir le départ, puis l'arrivée. Pose le robot sur la ligne, juste avant le point de départ, dans l'orientation choisie : il démarre dès le clic.

Position sur la grille

D : départ. A : arrivée. La flèche est sur la dernière intersection atteinte, le trait bleu est l'étape en cours.

Image traitée

Vert : ligne détectée. Rouge : centre visé. Cadre orange : intersection.
